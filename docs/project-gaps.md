## 功能扩展优先级

1. 先完成现有网络和容器端到端证据，避免只增加配置而缺乏实测。
2. 如需要多人管理，增加认证、后端权限校验、审计日志，再引入资产写操作和工单流转。
3. 如需要持续巡检，增加任务调度、历史结果持久化、失败通知和数据保留策略。目前命令行巡检是单次运行。
4. 如需要生产可靠性，补充 TLS、离机备份与恢复演练、跨主机部署和数据库冗余。当前双应用仍共享宿主机、入口和数据库。

这些扩展不是已经实现的能力，也不是只读实验必须加入的功能。先以现有范围可运行、可复现作为完成标准。
